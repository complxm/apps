# Slipbox

A Luhmann-style zettelkasten for the phone, following Bob Doto's *A System for Writing* (2024).

- **Inbox**: fleeting notes. Make a main note from each one, put it to sleep, or let it go.
- **Box**: main notes in address order (1.1, 1.1a, 1.2…). An address records which idea a note grew from; it is not a category.
- **Sources**: one reference note per book, video or talk: a page or timestamp and a few words. Make main notes from captures.
- **Views**: keyword index (plus a random note), hub notes, structure notes, and clusters (where the box is growing).
- **Write**: drafts built from notes, with an outline stage and a creative log.

The editor nudges the method: statement titles, "but"/"however" splits, a reason for every link, duplicate titles, taken addresses.

Data stays in the browser's localStorage on the device. Back up and restore (JSON) or export Markdown from More.
Plain HTML/CSS/JS, FVL tokens and fonts from `/apps/vendor/fvl/`. `sw.js` keeps the app's files for offline use (network first).
